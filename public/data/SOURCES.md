Retrieved: October 10, 2026.

Selection: ways representing buildings, parking, gardens, and footways/paths/pedestrian spaces. Polygon rings and source coordinates are retained without simplification. OpenStreetMap object IDs remain in feature IDs and properties. The API may return complete ways extending beyond its requested bounding box.

Place marker centres are derived from OSM geometry, with UNBC Exchange from OSM node 8580971526. They are approximate centres rather than verified entrances. Names and campus numbers are curated using UNBC's official maps: https://www.unbc.ca/about-unbc/campus-maps

This dataset is a local snapshot and is not automatically updated.
