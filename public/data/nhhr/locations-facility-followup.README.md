# Facility follow-up location sources and scope

This asset contains 25 representative points: eight directory buildings/campuses, 11 existing facility references reused exactly, and six independently verified address-parcel references for capital reporting context. The additions view has nine source entries; Dr. Al Hogg remains unlocated.

A directory value of one describes source entry presence. It is not beds, staffing, clinical capacity, an independent acute hospital, research participation or live service availability. VGH and UBC pavilions retain their named-building grain; Whitehorse retains source province YT and one representative hospital-campus point.

New coordinates come from returned named OpenStreetMap objects and are checked against authoritative operator addresses/campus plans. No coordinates are invented, shifted or jittered. OSM attribution and ODbL apply to OSM-derived points: https://www.openstreetmap.org/copyright . Operator location links and exact OSM objects are embedded in each feature. Blackmore's OSM address tag conflicts with the operator; the primary 855 West 12th Avenue address is retained and the conflicting address is not used as an alias. Dr. Al Hogg's source and candidate points conflict spatially and are not mapped.

The six address-parcel coordinates are returned by the Province of British Columbia Address Geocoder, with CIVIC_NUMBER precision, scores 99–100 and parcelPoint location descriptors. Their 7 July 2026 coordinate base-data date is distinct from the original project periods. The returned copyright notice is Copyright © 2024 Province of British Columbia; its licence link is https://www2.gov.bc.ca/gov/content?id=A519A56BC2BF44E4A008B33FCF527F61 . These are address-parcel references, not verified building centroids.

The 11 reused capital points are current reviewed facility references. They do not locate historical equipment, establish project completion or describe current asset availability. Five reporting-site parcels are corroborated by operator period addresses. Two Mills equipment rows use a distinct historical-address parcel at 4720 Haugland Avenue; this is a current CIVIC_NUMBER parcel representation of the original address, not historical geometry, the former building centroid or the Ksyen building. Construction targets and the unverified Quesnel leasehold remain null. See facility-location-gap-review.json for exact geocoder receipts, operator sources and remaining gaps. The map counts printed project rows within one original report interval; it does not sum money or combine report periods.

See facility-followup-provenance.json for source hashes, exact source IDs, 64 published project-cell bindings and all 82 directory records matched to 79 existing sites. The source table had 46 capital rows; the full generic table plus original PDFs supports 64 and restores 18 omitted rows. The reports contain 30 rows for 2020–2022 and 34 for 2022–2024. A printed funding dash stays null.

Raw directory contacts, unrelated report tables, private paths and original PDF archives are not redistributed. These are bounded factual extracts with source attribution, not a grant of broader source redistribution rights.
