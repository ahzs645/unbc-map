# Verified hospital display locations

Reviewed on **2026-10-12**. This registry contains 84 verified physical display sites drawn from the exact source facility directory and hospital cost labels.

## Meaning and source coverage

The source directory has 61 IDs, including duplicate labels. All source IDs are retained while reviewed aliases collapse to one directory entry. A verified site count of one describes presence only. It is not clinical capacity, waiting patients, beds or surgical volume. Aggregate or unresolved names remain visible without a point.

The cost dataset retains all 363 original CIHI facility/fiscal-year records, including source suppression. A current display point provides hospital reporting context; it does not allocate past costs to a present-day building or claim the reporting entity's footprint has never changed. Multiple reporting labels at a shared site remain ambiguous unless an explicit source definition supports combining them. Costs are not summed or averaged.

## Independent location evidence

PGMaps / BCDataMapper health_place_registry is used read-only to propose names, addresses and official references. It is not accepted as location proof. Official facility pages establish identity/address, and Nominatim returns actual mapped OSM objects or exact-address objects. Bus stops, heliports, construction sites and city centroids are rejected. Returned coordinates are preserved without invented points, shifts or artificial jitter. A point may represent a campus or an address rather than an entrance or surveyed building position.

The exact source aliases, official reference titles, OSM objects and query URLs are recorded in hospital-facilities-provenance.json. The preparation script verifies source hashes and the reviewed location registry hash before generating the module/public mirrors. All unresolved source labels and reasons remain in the provenance and explorer rows.
